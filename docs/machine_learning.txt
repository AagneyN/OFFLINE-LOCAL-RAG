
# Machine Learning Fundamentals

## 1. Introduction to Machine Learning

Machine Learning (ML) is a branch of Artificial Intelligence that enables computer systems to learn patterns from data and make predictions or decisions without being explicitly programmed for every task.

Machine learning algorithms use historical data to identify relationships and patterns. These learned patterns are then used to make predictions on new, previously unseen data.

A typical machine learning workflow includes data collection, data preprocessing, feature selection, model training, model evaluation, and prediction.

## 2. Types of Machine Learning

Machine learning is commonly divided into three major categories: supervised learning, unsupervised learning, and reinforcement learning.

### 2.1 Supervised Learning

Supervised learning is a machine learning approach in which a model is trained using labelled data. Each training example contains input features and a known target or output.

The model learns the relationship between the input features and the expected output. It then uses this relationship to predict outputs for new data.

Common supervised learning tasks include classification and regression.

Examples include email spam detection, house price prediction, and disease classification.

### 2.2 Unsupervised Learning

Unsupervised learning uses unlabelled data. The dataset does not contain predefined target outputs.

The algorithm attempts to identify hidden patterns, structures, or relationships within the data.

Clustering and dimensionality reduction are common unsupervised learning techniques.

Examples include customer segmentation, grouping similar documents, and discovering patterns in purchasing behaviour.

### 2.3 Reinforcement Learning

Reinforcement learning is a machine learning approach in which an agent learns by interacting with an environment.

The agent performs actions and receives rewards or penalties based on those actions. Its objective is to learn a strategy that maximizes cumulative reward over time.

Important reinforcement learning concepts include agents, environments, actions, states, rewards, and policies.

Applications include robotics, game-playing systems, and autonomous decision-making.

## 3. Classification

Classification is a supervised learning task in which a model predicts a discrete category or class label.

For example, an email classification system may predict whether an email is spam or not spam.

Classification can be binary, involving two classes, or multiclass, involving more than two classes.

Common classification algorithms include Logistic Regression, Decision Trees, Random Forest, Support Vector Machines, and K-Nearest Neighbours.

## 4. Regression

Regression is a supervised learning task in which a model predicts a continuous numerical value.

For example, a regression model can predict the price of a house based on its size, location, and other features.

Common regression algorithms include Linear Regression, Decision Tree Regression, Random Forest Regression, and Support Vector Regression.

The main difference between classification and regression is the type of output. Classification predicts categories, while regression predicts numerical values.

## 5. Clustering

Clustering is an unsupervised learning technique that groups data points based on similarities.

Data points within the same cluster are generally more similar to each other than to points in other clusters.

K-Means is a widely used clustering algorithm. It divides data into a specified number of clusters by assigning observations to the nearest cluster centre.

Clustering is commonly used in customer segmentation, document grouping, and exploratory data analysis.

## 6. Dimensionality Reduction

Dimensionality reduction is the process of reducing the number of features in a dataset while attempting to preserve important information.

High-dimensional datasets may contain redundant or less useful features. Reducing dimensionality can simplify models, reduce computational requirements, and help visualize complex datasets.

Principal Component Analysis (PCA) is a widely used dimensionality reduction technique.

PCA transforms the original features into a smaller set of new variables called principal components. These components capture as much of the original data variance as possible.

## 7. Model Training and Testing

Model training is the process of teaching a machine learning algorithm to identify patterns from training data.

A dataset is commonly divided into training and testing subsets.

The training dataset is used to fit the model. The testing dataset is used to evaluate how well the trained model performs on unseen data.

A validation dataset may also be used during model development to tune hyperparameters and compare model configurations.

## 8. Overfitting and Underfitting

Overfitting occurs when a model learns the training data too closely, including noise and irrelevant patterns. Such a model may perform well on training data but poorly on unseen data.

Underfitting occurs when a model is too simple to capture important patterns in the training data. It generally performs poorly on both training and testing data.

Regularization, cross-validation, feature selection, and appropriate model complexity can help improve generalization.

## 9. Model Evaluation Metrics

Classification models can be evaluated using accuracy, precision, recall, and F1-score.

Accuracy measures the proportion of correctly predicted observations among all observations.

Precision measures the proportion of positive predictions that are actually positive.

Recall measures the proportion of actual positive observations correctly identified by the model.

F1-score is the harmonic mean of precision and recall.

Regression models can be evaluated using Mean Absolute Error (MAE), Mean Squared Error (MSE), and Root Mean Squared Error (RMSE).

MAE calculates the average absolute difference between actual and predicted values.

MSE calculates the average squared difference between actual and predicted values.

RMSE is the square root of MSE and expresses prediction error in the same units as the target variable.

## 10. Common Machine Learning Libraries

Python provides several libraries for machine learning development.

NumPy supports numerical computing and array operations.

Pandas provides tools for data manipulation and analysis.

Matplotlib supports data visualization.

Scikit-learn provides implementations of machine learning algorithms, preprocessing tools, model selection methods, and evaluation metrics.

These libraries are commonly used together in machine learning workflows.
